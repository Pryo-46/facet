name: write-decision-table
description: 仕様整理ツールのデシジョンテーブルファイル（type=decisionTable / schemaVersion 1 の JSON）を、会話の内容から作成・追記・更新する。「デシジョンテーブルを作って」「判定表にして」といった依頼のほか、「条件の組み合わせで結果が決まる」「どの組み合わせでどうなるか整理して」「組み合わせを漏れなく洗い出して」と言われたとき、複数の条件を同時に見て結果を決める仕様を表にしたいとき、プロジェクトフォルダに type: decisionTable の JSON があるときは、明示的に「デシジョンテーブル」と言われていなくてもこのSkillを使うこと。ただし原因の分解や場合分けの木はロジックツリー（write-logic-tree）、仮説・検証を伴う整理は課題ツリー（write-issue-tree）の担当なので、そちらを使う。IDの採番とスキーマ検証・行の直積への整列・正規形での書き出しは同梱スクリプトが行うため、手書きでJSONを作らない。
