# アプリアイコン生成 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** スペック `docs/superpowers/specs/2026-08-14-app-icon-design.md` のデザイン（7面ファセット・深青＋Ember）で `src-tauri/icons/` の全アイコンを差し替える。

**Architecture:** マスター SVG（hex 色焼き込み・フルブリード）を `src-tauri/icons/icon.svg` としてコミットし、公式 `tauri icon` CLI を2回実行する。1回目はフルブリード SVG から全形式（Windows .ico / Square*.png / 各種 png / icns）を生成、2回目は余白入りラッパー SVG（一時ファイル）から別ディレクトリに生成して `icon.icns` だけを採用する。

**Tech Stack:** Tauri CLI（`npx tauri icon`。SVG を直接受け取り内部でラスタライズする）。新規依存なし。

## Global Constraints

- `src-tauri/icons/` のファイル名は現状のまま差し替える。`src-tauri/tauri.conf.json` は変更しない
- 新規の恒久依存・自作スクリプトを追加しない
- 色は必ず hex（スペック記載の変換値）。SVG に oklch を書かない（`tauri icon` のラスタライザが解さない）
- `tauri icon` が生成する `android/` `ios/` サブディレクトリはコミットしない（このリポジトリにモバイルターゲットはない）
- 一時ファイルはスクラッチパッド（`$SCRATCH` と表記。任意の一時ディレクトリでよい）に置き、リポジトリに残さない
